# 视频压缩（video-compress-cn）

安卓端**硬件加速**视频格式转换与压缩工具：在尽量保留画质的前提下压缩体积。界面全中文，安装包约 95 KB，无第三方依赖。

## 下载
到 [Releases](https://github.com/Acalaxiaka/video-compress-cn/releases) 下载 `VideoCompress-v1.0.1.apk`（Android 8.0+）。

## 功能
- **硬件编码**：MediaCodec + MediaMuxer 直接调用手机硬件编码器；优先 **HEVC/H.265**，不支持时回退 **H.264**；Android 14+ 且有**硬件 AV1 编码器**时自动使用 AV1。
- **编码器检测**：启动时用 MediaCodecList 列出本机 HEVC / H.264 / AV1 / AAC 编码器（硬件或软件、最大分辨率）。
- **批量**：系统文件选择器多选（也支持从相册“分享”到本应用），队列依次处理，可随时取消。
- **安全**：原视频绝不修改；输出保存到 `Movies/AngioCompress/`（MediaStore）。
- **预设**
  | 预设 | HEVC 基准 bpp | 说明 |
  |---|---|---|
  | 高画质 | 0.10 | 接近视觉无损 |
  | 均衡（默认） | 0.065 | 1080p30 约 4 Mbps |
  | 小体积 | 0.035 | 短边限制 1080p，音频 AAC 96k |
  | 自定义 | 0.02–0.15 | 编码格式、分辨率（保持/1080p/720p）、画质滑块或指定码率、音频复制或 AAC 64–192k |
- **码率规则**：码率 = 宽 × 高 × 有效帧率 × bpp × 编码系数（H.264 ×1.45，AV1 ×0.75）；30fps 以上按 0.6 递减；同时不超过源码率（按像素比例折算，×0.75，高画质 ×0.9）。
- **绝不放大**分辨率；**保持原帧率**；**保留旋转信息**（竖屏视频方向正确）。
- **防止越压越大**：预计体积 ≥ 原文件 95% 时跳过；压缩后实际更大也不保存，并提示。
- 显示进度、剩余时间、预计体积、压缩前后大小与压缩比。
- 输入：MP4、MOV、3GP、MKV、WebM（取决于系统解析器）；AVI 等不支持时给出中文错误提示。输出统一为 MP4。

## v1.0.1 更新
- 修复长视频在约 74% 处卡死且无法取消的问题：MP4 单文件超过约 3.5 GB 自动分段（MediaMuxer 32 位偏移上限 4 GB）。
- 异步 MediaCodec 流水线，所有等待均带超时；看门狗 20 秒无进展即保存已完成部分并给出错误码（E-STALL / E-MUX / E-CODEC / E-INIT / E-IO）。
- 取消在 5 秒内必定生效并复位界面。
- 前台服务 + 通知栏进度，熄屏/切后台继续处理。
- 更准确的剩余时间（60 秒滑动窗口速度 + 平滑）。
- 输出直接写入相册，不再占用双倍临时空间。
- 屏幕诊断日志及“复制日志”按钮。

## 关于软件编码兜底
FFmpegKit 已于 2025 年停止维护并下架二进制，本应用**不内置软件编码库**（会使体积增加数十 MB）。硬件编码器不可用时，会使用系统自带的软件 H.264 编码器（Android 系统组件）。

## 构建
使用命令行 Android SDK（build-tools 35、platform 35、JDK 17），无需 Gradle：
```bash
cd android && ./build.sh ../VideoCompress.apk   # 需自备 android-keystore/release.jks 与 password.txt
./test/run_tests.sh                               # 码率逻辑单元测试
```
构建脚本保证 `resources.arsc` 与 `classes.dex` 以 STORED（不压缩）方式存放，避免小米安装错误 -124。

## 已知限制
- 未在真机上全面测试；不同厂商硬件编码器对分辨率/码率模式的支持差异较大，个别设备可能需要在“自定义”中改用 H.264 或 720p。
- HDR（10-bit）视频会按 8-bit SDR 重新编码，色彩可能变化。
- Android 15 对前台服务有每日约 6 小时上限，超长任务可能被系统终止。
- 多声道音频重新编码时简单取前两个声道。
